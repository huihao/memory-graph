# Browser Extension Icons

This directory should contain the following icon files:
- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

To generate icons, you can use any image editor or online tool to create simple icons with a graph/network theme.

For now, you can use placeholder images or generate them using tools like:
- https://www.favicon-generator.org/
- GIMP, Photoshop, or other image editors
- SVG to PNG converters

The icons should represent the concept of a knowledge graph or connected network of information.
